## 2026-08-16_loop1_csi300_alpha158plus.pdf

**这是什么**:第一次跑通完整 RD-Agent + Qlib 闭环的完整 UI 快照,对应 Codespace 里的日志目录 `log/2026-08-16_06-35-38-526479`。

**用的什么数据 / 什么配置**(截图自报告第 5 页的 Config 表):

| 项目 | 值 |
|---|---|
| Dataset | CSI300(沪深300成分股) |
| Model | LGBModel(LightGBM) |
| Factors | Alpha158 Plus(官方 Alpha158 因子库 + 这次新增的 3 个因子) |
| 训练区间 | 2008-01-01 ~ 2014-12-31 |
| 验证区间 | 2015-01-01 ~ 2016-12-31 |
| 测试区间 | 2017-01-01 ~ 2020-08-01 |
| 数据源 | 官方推荐的社区替代源(microsoft/qlib 官方数据临时下架期间),`chenditc/investment_data` |

**这次做的测试是什么**:RD-Agent 提出假设"5日动量、5日波动率、5日成交量变化这类简单量价因子能捕捉短期趋势和风险",写出对应因子代码,Qlib 训练 LightGBM 模型,分别跑基线(不含新因子)和加了新因子两版,对比结果。

**怎么回测的**:Qlib 的标准流程——`qrun conf_baseline.yaml` 和 `qrun conf_combined_factors.yaml`,内部依次是:读数据 → 训练模型 → 生成预测信号 → 组合策略模拟(TopK 策略,买入预测收益最高的前50只、卖出表现最差的5只)→ 计算收益/回撤/IC 等指标。

**结果**:加了新因子后 IC 从 0.0274→0.0310,年化超额收益 3.78%→6.35%,但最大回撤也从 -8.49%→-13.64%(收益提升的代价是风险变大)。RD-Agent 判定假设成立,接受为新 SOTA,下一轮打算加 ATR/RSI 类因子来平衡风险。

**怎么读这份 PDF**(如果你以后忘了里面每个部分是什么):
- 第 1-2 页:场景说明 + 关键指标对比图
- 第 3-4 页:"Task Completion Analysis" —— 3 个因子各自花了几轮代码调试才写对(不是模型准确率,是"代码写没写对"的调试进度)
- 第 4-5 页:具体因子代码 + Qlib 配置表
- 第 6 页:Qlib 官方回测报告图(收益曲线、回撤曲线)
- 第 7-8 页:RD-Agent 自己对这轮结果的文字分析和下一轮计划
